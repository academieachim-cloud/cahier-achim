# 📚 Cahier interactif ACHIM

Cahier numérique pour les élèves de CP de l'**École ACHIM** (Année 2025-2026).

## ✨ Fonctionnalités

- 📄 Chargement de PDF et d'images
- ✏️ Dessin et annotation sur les pages
- 🗣️ Lecture audio des consignes
- ✂️ Atelier collage (découpage d'images)
- 📊 Fiche de suivi pédagogique
- 📧 Envoi du travail à l'école
- 🌙 Thème clair/sombre automatique
- 📱 Installation comme application (PWA)
- 💾 Sauvegarde automatique locale

## 🚀 Utilisation

Ouvre simplement https://academieachim-cloud.github.io/cahier-achim/
